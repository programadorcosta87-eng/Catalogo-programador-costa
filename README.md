# Catálogo Programador Costa

Landing page profissional de serviços de desenvolvimento web e design gráfico.

🔗 Acesse o projeto: https://catalogo-programador-costa.lovable.app

---

## 📋 Sobre o projeto

O **Catálogo Programador Costa** é uma landing page desenvolvida para apresentar serviços de desenvolvimento web e design gráfico de forma profissional, organizada e objetiva.

A página foi pensada para funcionar como uma apresentação digital dos serviços, permitindo que potenciais clientes conheçam as soluções disponíveis, entendam como funciona o processo de trabalho e encontrem facilmente os canais de contato.

O projeto prioriza uma apresentação visual moderna, navegação simples e adaptação para diferentes dispositivos.

---

## ✨ Funcionalidades

* Apresentação clara dos serviços
* Design moderno com visual tecnológico
* Seções: Serviços, Como funciona e Contato
* Totalmente responsivo
* Foco em conversão
* Estrutura organizada para apresentação profissional
* Interface adaptada para dispositivos móveis
* Elementos visuais e animações para melhorar a experiência

---

## 🛠️ Tecnologias

* HTML5
* CSS3
* JavaScript
* Design moderno com animações
* Hospedado no Lovable

---

## 🎯 Objetivo do projeto

O principal objetivo é apresentar serviços de desenvolvimento web e design de maneira profissional, utilizando uma página própria como catálogo digital.

Além da finalidade comercial, o projeto demonstra conhecimentos relacionados à criação de interfaces responsivas, organização de conteúdo, hierarquia visual, experiência do usuário e desenvolvimento de páginas voltadas para conversão.

---

## 📱 Responsividade

A interface foi desenvolvida para se adaptar a diferentes tamanhos de tela, proporcionando uma experiência adequada tanto em computadores quanto em dispositivos móveis.

A organização das seções foi pensada para facilitar a navegação e permitir que as informações principais sejam encontradas rapidamente.

## 🚀 Como executar localmente

### 1. Clone o repositório

```bash
git clone https://github.com/programadorcosta87-eng/Catalogo-programador-costa.git
```

### 2. Entre na pasta

```bash
cd Catalogo-programador-costa
```

### 3. Execute localmente

Como o projeto é composto por HTML, CSS e JavaScript, basta abrir o arquivo:

```text
index.html
```

diretamente no navegador.

Também é possível utilizar qualquer servidor local para servir os arquivos do projeto.
